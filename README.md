## 🔍 Project Overview

A **deep learning project** to classify flower images into **five categories** using **Convolutional Neural Networks (CNNs)**.  

- 🌺 **Lotus**  
- 🌸 **Lily**  
- 🌻 **Sunflower**  
- 🌼 **Orchids**  
- 🌷 **Tulip**  

Key Features:  
-  Built with **Keras + TensorFlow** for model training.  
-  Visualized with **Matplotlib**   
- Supports **GPU acceleration** for faster training.
